# 🚀 Featured Projects

## 1. Braylix — CNC Braille Embossing Machine

**Graduation Project — MSA University**

A compact CNC-based Braille embossing machine designed to convert digital text into physical Braille.

### Key Features
- Standalone SD-card text input
- X-Y belt-driven positioning system
- Solenoid-based embossing mechanism
- Arduino Mega 2560 control
- RAMPS 1.4 motion-control platform
- LCD user interface
- Automatic homing using limit switches

### My Contributions
- Mechanical design
- CAD development
- CNC motion system
- Electrical integration
- Arduino programming
- System testing and optimization
- Prototype development

**Technologies:**  
`SolidWorks` `Arduino` `CNC` `RAMPS 1.4` `NEMA 17` `A4988` `CAD`
